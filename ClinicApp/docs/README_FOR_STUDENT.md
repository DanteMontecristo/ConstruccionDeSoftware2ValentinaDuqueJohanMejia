# Documentación para estudiantes (Proyecto ClinicApp)

Bienvenido a la documentación orientada a estudiantes de ingeniería de software con nivel básico de programación. Aquí encontrarás archivos separados que explican, con ejemplos y orientación práctica, los conceptos principales del proyecto:

- `docs/ARCHITECTURE.md` — explicación de la arquitectura del proyecto (capas, flujo, patrones).
- `docs/DOMAIN.md` — descripción del dominio (modelos y conceptos del dominio clínico).
- `docs/SERVICES.md` — los servicios del dominio y cómo se usan (casos de uso y servicios de aplicación).
- `docs/JPA_ENTITIES.md` — manejo de entidades JPA y reglas para persistencia.
- `docs/ENDPOINTS.md` — lista de endpoints, roles asociados y ejemplos de request/response.

Lee los archivos en el orden anterior para obtener una progresión lógica: arquitectura → dominio → servicios → entidades → endpoints.

Si quieres, puedo generar también una versión PDF, crear pruebas de integración o añadir un diagrama de despliegue.
